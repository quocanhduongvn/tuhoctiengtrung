Đưa ứng dụng lên Netlify miễn phí (30 giây)

Ứng dụng này được thiết kế theo dạng Zero-Build Static Web App, nghĩa là bạn không cần cài đặt Node.js hay chạy lệnh build phức tạp. Bạn có thể deploy lên Netlify theo 1 trong 2 cách sau:

Cách 1: Kéo thả trực tiếp qua Netlify Drop (Khuyên dùng)

  1. Truy cập trang web: app.netlify.com/drop (Đăng nhập miễn phí).
  2. Mở thư mục dự án trên máy tính: E:\TOI-TU-HOC.
  3. Kéo toàn bộ thư mục này và thả vào ô vuông trên trang Netlify Drop.
  4. Netlify sẽ cấp ngay một tên miền miễn phí dạng: tu-hoc-tieng-trung.netlify.app để bạn lưu vào Bookmark điện thoại hoặc máy tính ôn tập mọi lúc mọi nơi!

Cách 2: Đẩy lên GitHub rồi kết nối Netlify (Tự động cập nhật)

Tạo repository trên GitHub, push mã nguồn từ E:\TOI-TU-HOC lên. Sau đó trên Netlify chọn "Add new site" ➔ "Import an existing project" ➔ Chọn GitHub. Mỗi lần bạn học xong bài mới và commit, Netlify sẽ tự động cập nhật!
